# Sifa Shereen M — Personal Portfolio

A modern, premium, fully responsive personal portfolio website built with **pure HTML5, CSS3, and Vanilla JavaScript** — no frameworks, no build step. Deployable directly to **GitHub Pages**.

## ✨ Features

- Sticky navigation bar with active-link highlighting
- Smooth scrolling & scroll progress bar
- Typing effect for the hero role
- Scroll reveal animations (IntersectionObserver)
- Animated stat counters
- Glassmorphism cards & gradient accents
- Dark premium theme
- Education timeline
- Modern project cards
- Certifications, achievements & interests sections
- Contact form with client-side validation (mailto fallback)
- Scroll-to-top button & loading animation
- SEO meta tags + Open Graph / Twitter cards
- Fully mobile responsive
- Respects `prefers-reduced-motion`

## 📁 Project Structure

```

├── index.html        # Markup for all sections

├── assets/
│   ├── profile.jpg               # Profile photo
│   └── Sifa_Shereen_Resume.pdf   # ← Add your resume here

```

## 🚀 Deploy to GitHub Pages

1. Create a new repository and push these files to the `main` branch.
2. Go to **Settings → Pages**.
3. Under **Source**, select the `main` branch and `/ (root)` folder.
4. Save. Your site will be live at `https://<username>.github.io/<repo>/`.

No build process or npm commands are required — all paths are relative.

## 📝 Customization

- **Resume:** Place your resume file at `assets/Sifa_Shereen_Resume.pdf` so the "Download Resume" button works.
- **Profile image:** Replace `assets/profile.jpg` with your own photo.
- **Colors:** Edit the CSS variables in the `:root` block at the top of `style.css`.
- **Content:** All text lives in `index.html`.
